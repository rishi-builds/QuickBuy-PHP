Project Name: E-Commerce Website

Description:
This is a full-stack e-commerce website developed using PHP and MySQL.
It includes user authentication, admin panel, cart, checkout and order management.

Tech:-
HTML, CSS, JavaScript
PHP
MySQL
XAMPP (Localhost)

How to Run Project:
1. Install XAMPP
2. Copy project folder to htdocs
3. Import database.sql using phpMyAdmin
4. Update database credentials in db.php
5. Start Apache & MySQL
6. Open browser and go to http://localhost/my_project/index.php
